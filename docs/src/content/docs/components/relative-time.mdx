## Notes

**The rule this is built on:**

> A relative time is a convenience, never the only copy of the fact.

"Last week" is quicker to read than a date and useless the moment the reader
needs to say when something actually happened — and they cannot get it back,
because the page has thrown it away. So the element is a `<time>` with the
exact moment in `dateTime` and the real date in `title`: hovering shows it,
machines can read it, and nothing is lost by showing the phrase.

```tsx
<RelativeTime value={row.updated} />
<RelativeTime value={row.updated} numeric="always" />  {/* "1 day ago", not "yesterday" */}
```

**`Intl.RelativeTimeFormat` writes the phrase**, which is the whole reason
there is no date library here. "yesterday", "3 недели назад", "in 2 months" —
the plural rules and the special words for the nearest units are the part a
hand-written version gets wrong first, and it gets it wrong only in the
languages its author does not read.

What `Intl` does not decide is *which* unit to use: it is told "3" and "weeks".
Choosing between them is `relativeParts`, and it is the only arithmetic here.

**It rounds towards zero.** Rounding to nearest is the tempting alternative and
says "in 1 hour" 31 minutes before the meeting; truncating never claims more
time has passed than has.

**It does not update itself.** A component that re-renders every second to keep
"2 minutes ago" honest costs a timer per instance — a table of fifty rows is
fifty timers — to correct a number nobody is watching change. A product that
needs it re-renders the list on its own schedule, which is what `now` is for;
it also keeps tests off the clock.

**A date that is not a date renders as nothing.** "Invalid Date" is a string no
reader can act on and which looks like a value; an empty `<time>` with no
`dateTime` says the same to a machine.

## Props

| Prop | Type | Default | |
| --- | --- | --- | --- |
| `value` | `Date \| number \| string` | | Whatever the data already holds |
| `now` | `Date \| number` | read once at mount | What counts as now. Given, every row measures from the same moment |
| `locale` | `string` | the application's (`useLocale`) | |
| `numeric` | `'auto' \| 'always'` | `'auto'` | `auto` gives "yesterday" where the language has the word |
| `titleOptions` | `Intl.DateTimeFormatOptions` | medium date, short time | How the exact moment is written |

`formatRelative(value, locale, now?, options?)` gives the phrase alone (the
locale is required: a plain function has no provider to ask), and
`relativeParts(value, now?)` the count and unit behind it.
